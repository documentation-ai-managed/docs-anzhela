## Upgrade Instructions

Upgrade Anzhela to the latest version using these steps. You receive automatic notifications in your dashboard at `https://dashboard.example.com`.

<Steps>
  <Step title="Check Current Version" icon="package">
    Run the following command to verify your installed version:
    
````bash
anzhela --version
````
  </Step>
  <Step title="Backup Data" icon="database">
    Export your documentation:
    
    <CodeGroup tabs="CLI,Dashboard">
    ````bash
    anzhela export --all > backup.json
    ````
    ````javascript
    // From dashboard.example.com
    // Click Export > Full Backup
    ````
    </CodeGroup>
  </Step>
  <Step title="Update Package" icon="download">
    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm update anzhela-sdk@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn upgrade anzhela-sdk@latest
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify" icon="check-circle">
    Restart your instance and test core features.
  </Step>
</Steps>

<Callout kind="tip">
  Review the migration guide for v1.2.0 if you encounter deprecated API usage. Visit your dashboard for personalized upgrade paths.
</Callout>
