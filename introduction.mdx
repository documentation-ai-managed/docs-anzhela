## Overview

Anzhela empowers you to create, organize, and maintain project documentation in one centralized space. You streamline workflows by combining powerful editing tools, version control, and collaboration features tailored for teams. Whether you manage open-source projects or internal wikis, Anzhela scales with your needs, ensuring your docs stay current and accessible.

## Quick Start

Get up and running with Anzhela in minutes. Follow these steps to create your first documentation space.

<Steps>

<Step title="Sign Up" icon="user-plus">

  Visit `https://app.anzhela.com` and create a free account using your email or GitHub.

</Step>

<Step title="Create Project" icon="plus">

  Click **New Project** from the dashboard. Name it, add a description, and select visibility (public or private).

</Step>

<Step title="Add Your First Doc" icon="file-plus">

  Create a new page with the intuitive editor. Use Markdown for structure:

````markdown
# Welcome to My Project

This is your starting point.

## Quick Links

- [Installation](/installation)
- [API Reference](/api)
```
````

</Step>

<Step title="Publish and Share" icon="share-2">

  Hit **Publish** to make it live. Share the URL or embed it in your app.

  ```javascript
  // Embed Anzhela docs in your site
  embed.init({
    docId: 'your-doc-id',
    host: 'https://app.anzhela.com'
  });
  ```

</Step>

</Steps>

## Why Choose Anzhela

You select Anzhela for its balance of simplicity and power. It eliminates fragmented tools like Google Docs, Notion, or static GitHub wikis by offering:

- **Centralized Management**: One space for all project docs, reducing context-switching.
- **Customizable Spaces**: Tailor layouts with MDX components, themes, and custom domains.
- **Performance**: Lightning-fast search and rendering, even for large repositories.
- **Integrations**: Connect with GitHub, Slack, and Zapier for automated workflows.
