---
title: How do I create a new project?
description: Learn how to start a new project in Anzhela.
---

## Steps

1. Log in to your Anzhela dashboard
2. Click "New Project" on the top right
3. Enter the project name and description
4. Select a documentation template (optional)
5. Click "Create"

## Tips

- You can edit project details later
- Invite collaborators from the project page
