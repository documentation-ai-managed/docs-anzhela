## Overview

Create a new documentation space for any project in Anzhela.

<Steps>
  <Step title="Navigate to Dashboard">
    Click on "Spaces" in the main menu after logging in.
  </Step>
  <Step title="Create Space">
    Click "Add Space", give it a name, and choose visibility (public/private).
  </Step>
  <Step title="Add Content">
    Use the editor to add your first page or import markdown files.
  </Step>
</Steps>
